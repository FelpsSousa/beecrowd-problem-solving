# Contributing

This is primarily a personal learning and portfolio repository.

At the current stage, external contributions are not the focus. The repository is intentionally structured around my own study workflow, coding conventions, documentation levels, and problem-solving methodology.

## What is welcome

- constructive feedback
- issue reports about broken links or structure inconsistencies
- thoughtful suggestions about documentation clarity

## What is not the focus right now

- unsolicited code rewrites
- style changes that conflict with the repository conventions
- bulk submissions or automated additions

## Before suggesting changes

Please read:

- `docs/repository-philosophy.md`
- `docs/repository-conventions.md`
- `docs/git-workflow.md`
- `docs/documentation-standard.md`

## Main principle

This repository is not intended to be a raw collection of accepted answers. It is designed as a documented knowledge base that reflects long-term technical growth, clarity of reasoning, and consistent engineering practices.
